# wavalign — 排练双录音对齐工具

同一场排练、两台设备各自录的 WAV：开头基本能对上，越往后越漂。本工具按
剪辑标注的对应时间点（锚点），把**待校正录音**拉到**参考录音**的时间轴上，
供后续剪辑直接使用。

仅依赖 Python 标准库（3.9+），无需安装任何第三方包。

## 用法

```bash
# 完整对齐：一对锚点修起点差，多对锚点分段修漂移
python3 wavalign.py --ref 参考.wav --src 待校正.wav \
    --anchor 12.5 10.0 --anchor 5:00.2 4:58.1 \
    --out aligned.wav --report report.txt

# 锚点也可以写在文件里（每行：参考时间 待校正时间，# 为注释）
python3 wavalign.py --ref 参考.wav --src 待校正.wav --anchors marks.txt \
    --out aligned.wav --report report.txt

# 单独导出选定区间试听（与从完整输出里截取逐采样一致）
python3 wavalign.py --ref 参考.wav --src 待校正.wav --anchors marks.txt \
    --out clip.wav --start 60 --end 1:30
```

* 时间格式：`75.5`（秒）、`1:15.5`（分:秒）、`01:02:03.25`（时:分:秒）。
* 两个输入可以是**不同采样率**的 PCM WAV（8/16/24/32 位整型）。
* 输出采样率默认等于参考文件（可用 `--out-sr` 改）；位宽、声道数与声道
  顺序保持待校正文件原样。
* 不加 `--start/--end` 时输出覆盖整个参考时长。

## 对齐模型

* **一对锚点**：纯平移，只修起点差。
* **多对锚点**：相邻锚点之间线性伸缩（分段修漂移）；首对之前、末对之后
  按相邻段的速率外延。
* 输出时间轴 = 参考时间轴。每个输出采样 `n` 的源位置由分段仿射函数
  `p(n) = A + n·B` 唯一确定，因此：
  * 段与段相接处连续，**不多不漏一帧**（输出总帧数恒为
    `round(参考时长 × 输出采样率)`）；
  * `--start/--end` 导出的区间与完整输出的对应切片**逐采样一致**。
* 源内插值为线性插值（漂移修正的伸缩率通常极接近 1，听感影响可忽略）。

## 报告

`--report` 输出：

* 每个锚点的参考/待校正时间与输出采样位置；
* 每段的**原始区间**（待校正文件的采样与时间范围）、**伸缩幅度**
  （源秒/参考秒、漂移 ppm、源采样/输出采样）与输出范围；
* **有效输出范围**（映射落在待校正录音内的部分）；
* **缺口**：参考范围超出待校正录音的部分已补静音，每条 `GAP` 单独列明
  区间与原因（录音开始之前 / 结束之后）。

## 锚点校验

以下情况拒绝执行并指明具体哪一对（按输入顺序编号）：

* **顺序相反**：参考时间增加而待校正时间减少；
* **退化**：两对锚点参考时间相同、待校正时间相同，或在输出采样率下
  落到同一输出采样；
* **冲突**：相邻锚点隐含的伸缩率超出合理范围（默认 0.5–2.0，可用
  `--min-rate/--max-rate 调整`）。

## 说明与限制

* 待校正文件会整体读入内存（约文件大小的 1–1.4 倍），超长录音请留意内存。
* 纯 Python 处理速度约每分钟音频数秒；仅支持未压缩 PCM（不支持
  float/mp3 等编码的 WAV）。
