# 档案整页校正工具（page-corrector）

纯浏览器、完全离线的批量档案页校正工具：为每张斜拍 / 带翻页阴影 / 倒转 / 边缘难辨的扫描照片框出文档四角，透视校正到统一纸张比例的纸面坐标，可在纸面上补画**保留区 / 遮挡区**，逐页导出 **PNG + 原图↔纸面坐标转换信息 JSON**。

- 零第三方运行时依赖，只用浏览器 Canvas 2D 与原生 ES Module。
- 图片不上传，所有像素处理都在本机浏览器内完成。
- 核心几何 / 模板 / 批处理 / 导出信息均为 DOM-free 模块，带 40 项 Node 测试。

---

## 快速开始

ES Module 不能通过 `file://` 直接双击打开，请用任意静态服务器（仓库已有同样约定）：

```sh
cd page-corrector
npm test        # 运行核心测试（Node >= 20，开发验证用）
npm run demo    # 等价于 python3 -m http.server 4180
```

然后打开 <http://localhost:4180/>。

macOS 也可以在 Finder 里双击 **`启动工具.command`**，会自动起服务并打开浏览器
（首次若被 Gatekeeper 拦截：右键 → 打开）。

推荐使用 Chrome / Edge：支持直接选择输出文件夹批量写入；Safari / Firefox 可改用浏览器下载。

## 操作流程

1. **添加图片**（可多选），或点右上角 **生成核对示例 ▾** 加入三种自生成问题页。
2. 在左图拖动 **① 左上 → ② 右上 → ③ 右下 → ④ 左下** 四个控制柄：
   - 任意两角几乎重合、对边交叉、四边形内凹 / 退化时，**本次拖动会被拒绝**，控制柄停在上一个合法位置；
   - 底部红色提示条会明确指出**哪个角（以及哪个对角）需要调整**，相关角点标红，并在光标处显示红色“幽灵点”。
3. 右侧选择**纸张比例**（A4 纵/横、Letter、正方形、自定义、按四角估算）与**导出宽度 px**。右侧纸面结果会防抖实时预览。
4. 鼠标在两图间移动（或单击固定黄色标记）可**双向联动定位**：左图源像素 ↔ 纸面 `(u,v)` 与毫米数。
5. 用纸面标题栏的 **保留区 / 遮挡区** 工具在右侧拖框：
   - 区域始终以**纸面归一化坐标**保存，左图实时投影出同一块四边形；
   - 可在区域列表选择 / 删除，或选中后按 `Delete`；也可直接拖动已画好的区域；
   - **重新修改四角后**，区域的纸面位置不变、源图投影自动重算；点 **校验区域坐标映射** 检查“纸面 → 源图 → 纸面”的往返误差。
6. 右侧 **本页导出** 可立即下载当前页 PNG + JSON，并可 **✓ 采用此结果**。
7. **批量处理并逐页导出**：
   - 可选 **选择输出文件夹**（Chrome/Edge）直接写入 `页名.png` 与 `页名.transform.json`；
   - 或用浏览器下载 / 仅保留结果，之后在页面列表与“依次下载全部成功页”中取文件；
   - 大图**顺序逐页**处理以控制内存，进度条显示总进度；处理中可 **取消后续页**，当前页会在下一像素块停止，尚未开始的页标记为“已取消”；
   - 已 `success / cached` 的页保留结果，可直接采用、单独下载；
   - 成功结果以 `pageKey + 配置签名` 为键存入 IndexedDB。重新加入同名同大小同修改时间的文件、且四角 / 比例 / 区域未变时，会显示“缓存可采用”，批处理直接命中缓存。

### 模板与单页覆盖（独立保存）

- **保存为全批模板**：把当前四角 / 比例 / 输出宽度 / 遮挡色 / 区域存为全批模板，所有“跟随模板”的页面使用它。
- **另存为本页覆盖**：复制当前设定为该页的独立覆盖，之后该页的修改自动保存到覆盖；**清除本页覆盖** 即恢复跟随模板。
- 两者使用不同的 localStorage 键，互不影响：
  - `page-corrector:template:v1`
  - `page-corrector:overrides:v1`（按 `文件名#大小#修改时间` 索引）
  - `page-corrector:adopted:v1`（采用标记）
- 右侧面板还可分别 **导出 / 导入全批模板 JSON** 与 **全部单页覆盖 JSON**，便于备份或换机器。

> 批量导出只使用“已保存”的模板 / 覆盖。若当前页有未保存调整，开始批量时会询问存入模板还是本页覆盖。

## 导出的坐标转换信息

每页导出 `<文件名>.png`（遮挡区已按设定颜色栅格化）与 `<文件名>.transform.json`，主要字段：

```jsonc
{
  "sourceImage": { "width": 4032, "height": 3024 },
  "paper": {
    "coordinateSystem": "paper-normalized",
    "origin": "top-left", "axes": "x-right, y-down",
    "unit": "normalized [0,1]",
    "ratio": { "widthOverHeight": 0.7071 /* … */ },
    "exportedPixels": { "width": 2480, "height": 3508 }
  },
  "cornerOrder": ["topLeft", "topRight", "bottomRight", "bottomLeft"],
  "corners": {
    "sourcePixels": [/* …4 点 */],
    "sourceNormalized": [/* …4 点 */]
  },
  "matricesRowMajor": {
    "sourceNormalizedToPaperNormalized": [/* 9 个数，行优先 3×3 齐次矩阵 */],
    "paperNormalizedToSourceNormalized": [/* … */],
    "sourcePixelsToPaperNormalized": [/* … */],
    "paperNormalizedToSourcePixels": [/* … */],
    "paperPixelsToPaperNormalized": [/* … */],
    "paperNormalizedToPaperPixels": [/* … */]
  },
  "regions": [
    { "type": "mask", "paperNormalized": { "x": 0.62, "y": 0.12, "w": 0.22, "h": 0.18 } }
  ]
}
```

坐标约定：

- **纸面归一化坐标 `(u,v)`**：纸面左上角 `(0,0)`、右下角 `(1,1)`，x 向右、y 向下。
- A4 预设下 `1u = 210 mm`、`1v = 297 mm`（JSON 的 `paperNominalSize` 给出比例单位）。
- 齐次变换用法：`[x', y', w']ᵀ = H · [x, y, 1]ᵀ`，再 `x'/=w'、y'/=w'`。
- 导出 PNG 像素与纸面归一化是纯缩放：`X = u * exportWidth`，`Y = v * exportHeight`。

后续识别端可直接用这些矩阵把识别框从纸面坐标反算回原图，或把原图检测结果统一到纸面坐标。

## 自生成核对页与已知坐标

菜单 **生成核对示例** 在浏览器内用 Canvas 生成 `1280×960` 源图：先画平整 A4 网格纸与红圈核对点，再按内置“真值四角”做透视投影，并叠加桌面、翻页阴影、不均匀光照；“边缘难辨页”使用近邻配色、柔化边缘。每张示例都带真值，界面中：

- 青色虚线框 / 菱形 = 真值四角与核对点的真实源图位置；
- 橙色叉 = **当前四角**反算的核对点，连线即偏差；
- 核对表面板给出每点的纸面坐标、A4 毫米坐标与当前偏差（mm / 源图像素）；
- **应用示例真值四角** 后最大偏差应为 `0.00 mm`，可用来验证整条矩阵 / 导出链路；
- **下载本页核对坐标 JSON** 可取得完整真值。

## 测试与自检

```sh
npm test     # node --test test/*.test.js：40 项
npm run smoke # 可选：本机无头 Chrome CDP 端到端冒烟（自动起静态服务与 Chrome）
```

测试覆盖：

- `geometry.test.js`：四角合法性（重合 / 交叉 / 内凹）、提示、DLT 单应矩阵、求逆、往返、恒等 warp、透明边、取消信号；
- `templates.test.js`：模板 / 覆盖独立键、合并优先级、坏 JSON 修复、签名缓存失效；
- `regions.test.js`：拖框归一化、区域投影、改四角后的往返一致性；
- `batch.test.js`：顺序执行、取消后续页、普通错误继续、缓存命中；
- `compose.test.js` / `export-meta.test.js`：遮挡栅格化、导出矩阵往返；
- `fixtures.test.js`：三种示例真值四角合法、核对点投影自洽；
- `app-bootstrap.test.js`：用 Fake DOM/Canvas 在 Node 中真实引导 `src/ui/app.js`，跑通示例生成 → 角点拒绝 → 真值 → 区域校验 → 模板/覆盖存储 → 小尺寸批量导出。

> 当前自动化沙箱可能禁止 Chrome 创建 ProcessSingleton socket，导致 `npm run smoke` 在沙箱内启动不了 Chrome；
> 这是环境限制。请在普通终端运行它，或直接按“快速开始”在浏览器手测。Node 测试不依赖 Chrome。

## 实现备注

- 四角 → 纸面用 4 对对应点做 DLT + 高斯消元求 3×3 单应矩阵；导出时逐输出像素反查源图并双线性采样。
- 预览使用最长边 1000px 的降采样源与 720px 宽纸面，导出仍走原图全分辨率。
- 超大图受浏览器 Canvas 最大边长 / 面积限制；若 `getImageData` 失败，该页会在批次中标记失败而不影响其它页。
