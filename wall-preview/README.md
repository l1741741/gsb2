# 弧形展墙贴图预览（离线）

在浏览器里预看一张长画贴到弧形展墙（已知半径和起止角的圆柱片）上的效果，重点核对**接缝附近的线条是否连续**。纯本地静态页面，无第三方依赖、无网络请求。

## 运行

```sh
npm run demo     # 然后打开 http://localhost:4174/
npm test         # 几何与项目文件的单测（Node 20+）
npm run samples  # 重新生成 samples/ 下的样例图与样例项目
```

打开页面后可直接「导入项目」载入 `samples/full-circle.project.json`（满圈跨缝）或 `samples/partial-wall.project.json`（不足一圈），样例项目内嵌图像，无需再导 PNG。

## 功能对照

1. **导入与双视图**：导入本地 PNG 作为画面，导入/添加实物定位点；「展开图 / 墙体预览」一键切换。
2. **接缝接续与空白**：满圈（跨度恰 360°）时画面跨起止缝按周长回绕，图案连续；不足一圈时墙面之外的区域留空，绝不重复贴图。展开图在满圈时显示红色起止缝线和两端「接缝对照带」，可直接核对跨缝线条。
3. **定位点联动与测量**：同一定位点在两个视图都能点选，侧栏显示它到起始边/结束边（满圈时为接缝）和底边/顶边的实际毫米距离；「翻面观看」只镜像投影，距离读数不变（有几何单测保证）。
4. **导出 / 导入 / 校验**：「导出项目 JSON」包含墙面参数、画面布置、定位点及展开坐标（mm，原点在起始边底角）；「导出裁切预览 PNG」输出墙面展开范围的合成图。重新导入项目 JSON 可完整还原；非法角（结束角 ≤ 起始角、跨度 > 360°）、越界画面、相距不足 1mm 的冲突定位点都会逐条指出。
5. **样例**：`samples/` 下两组，均由 `tools/make-samples.mjs` 离线生成（纯 Node zlib 编码 PNG），不取材于网络。

## 结构

- `src/geometry.js` — 圆柱片展开、角度/弧长互转、满圈回绕、画面覆盖采样、定位点到边距离、投影。纯函数，Node 可直接测。
- `src/project.js` — 项目 JSON 的导出（含展开坐标）与导入校验。
- `src/app.js` — 页面交互与两种视图的 Canvas 2D 绘制。
- `tests/` — `node --test` 单测，覆盖跨缝接续、不足一圈不重复、翻面测量不变、非法角与冲突定位点报错。
- `tools/make-samples.mjs` — 样例生成器（内置极简 PNG 编码器）。

## 坐标约定

- 展开坐标：x = 距起始边的弧长 mm，y = 距底边高度 mm。
- 满圈时 `unwrapped.artworkRectMm.x1` 可能大于展开总长，表示画面跨过起止缝回绕。
- 定位点冲突判定：水平与垂直距离均小于 1mm。
