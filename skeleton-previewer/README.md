# 骨骼动作预览器（skeleton-previewer）

离线 2D 骨骼动作预览工具：TypeScript + Canvas 2D，数据全部来自本地 JSON，无第三方运行时依赖。

针对的问题：动画师换动作后左手穿过道具、关节瞬间翻向。工具用**纯函数求值** + **统一的最短弧角度规则** + **双骨骼 IK 钳制**来定位和验证这类问题。

## 环境要求

- Node.js 20+（构建、测试、命令行导出）
- 现代浏览器（可视化预览）
- 仅开发依赖 `typescript`，无运行时依赖

## 使用

```sh
npm install        # 安装 typescript
npm test           # 构建并运行单元测试
npm run demo       # 构建并启动 http://localhost:4817/
npm run export     # 导出全部场景关键时间点数值到 stdout（JSON）
npm run export -- pin-hand-out-of-reach   # 只导出指定场景
```

浏览器界面：场景下拉框选择样例；播放/暂停、±1/60s 逐帧、拖动时间轴、0.25×–2× 变速、循环开关；勾选启用挂点固定，可直接在画布上拖动固定目标；「导出关键时间点数值」下载 JSON。

## 目录

```
data/character.json   骨骼层级、挂点、道具、IK 链条
data/clips.json       动作片段（位置/旋转关键帧，角度单位为度）
data/scenarios.json   场景编排：片段序列、过渡、固定点、导出时间点
src/                  求值核心（纯函数）与 Canvas 绘制
tests/                node:test 单元测试
```

## 核心规则

1. **纯函数求值**：`evaluateFrame(scene, time)` 的输出只取决于输入，不维护跨帧状态。拖动时间轴、倒放、变速播放时，同一时刻的姿势与挂点坐标逐位一致（有测试保证）。
2. **最短弧角度规则**：所有角度差归一化到 (-180°, 180°]，关键帧插值与过渡混合都走最短弧。例如 170° → -170° 经过 ±180°（20° 短路），不会反向扫 340° 造成关节翻向。
3. **局部空间过渡**：两段动作的混合发生在骨骼局部空间，世界变换之后自顶向下合成，因此过渡全程父子坐标关系保持一致。
4. **IK 不拉长骨骼**：双骨骼解析解把目标距离钳制到 [|l1−l2|, l1+l2]，超出可达范围时末端停在可达边界，界面用红色虚线和 Δ 数值显示不可达偏差。

## 样例场景（data/scenarios.json）

| 场景 | 覆盖点 |
| --- | --- |
| `transition-carry-to-wave` | 0.8s 过渡的开始/中间/结束，左臂 120°→-160° 跨半圈 |
| `short-transition` | 0.2s 短区间过渡 |
| `pin-hand-out-of-reach` | 左手固定到臂展之外，显示不可达偏差 |
| `pin-foot-planted` | 走路中左脚在时间窗内固定到地面（可达） |

每个场景的 `exportTimes` 定义了导出的关键时间点；导出的 JSON 包含每根骨骼的世界位置/旋转、全部挂点坐标和 IK 偏差。
