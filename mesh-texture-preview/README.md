# 织物网格贴图预览 / Mesh Texture Preview

给纹样设计人员的离线检查工具：把一张展开的织物纹样贴到一张可拖动的三角网格上，拖动控制点即可看到拼缝有没有变形、哪一块被拉伸、哪一片翻了面。

纯前端、零第三方运行时依赖：TypeScript + WebGL2，外加一个只在 Node 工具链里使用的 TypeScript 编译器。

## 快速开始

```sh
cd mesh-texture-preview
npm install          # 仅安装 TypeScript（编译器），无运行时依赖
npm run build        # 编译 src/ → build/
npm run demo         # 在 http://localhost:4174/ 打开
```

打开页面即自动载入「格纹」样例。右上角可在三个内置样例之间切换：

| 样例 | 内容 | 想看到什么 |
| --- | --- | --- |
| 格纹 `gingham` | 4×4 干净网格，所有拼缝连续 | 纹理贴着网格、边界与连续拼缝正常 |
| 断开拼缝 `split` | 沿 x=100 切成两片，右侧单独取样 | 4 条拼缝声明为「断开」，两侧各取各的纹理坐标 |
| 翻面 `flipped` | 一个控制点被拖过对边 | 洋红三角 + 诊断面板翻面计数，拖回即修复 |

## 操作

- **左键拖动白色控制点**：移动布面顶点，纹理随之局部拉伸/压缩；松开记一步可撤销。
- **空格 + 拖动 / 中键**：平移视图；**滚轮**：以光标为中心缩放。
- **画布左栏是布面位置**，**右栏是纹理坐标**：右栏直接在纹理图上显示每个三角形的 UV 布局，两侧断开的拼缝会在这里分成两条线。
- **点选顶点 / 三角形 / 拼缝**：右侧「局部数值」显示对应的雅可比、奇异值、两侧 UV 偏差、逐段取样表。
- **纹理栏里拖动角点**：直接编辑 UV，可手动制造或修复断开拼缝。
- **Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做**。
- 视图工具栏：纹理 / 拉伸 / 线框三种通道；边界、拼缝、控制点、网格线叠加；坏片「保留 / 停用」。

## 数据与导出

- **载入 PNG**：任意本地纹理；UV 在 [0,1] 之外时按重复纹理处理。
- **载入网格**：`.json`（本工具格式）、`.obj`（`v`/`vt`/`f`）、`.fabricmesh`（自带样例的文本格式）。
- **导出 mesh.json**：几何 + 每角点 UV + 拼缝声明 + 诊断阈值，并附一份导出时的诊断记录。
- **导出预览 PNG**：用内置 CPU 光栅器渲染，不依赖显卡；浏览器内导出用未压缩 deflate 保证逐字节可重复（文件略大），样例资产则由 `tools/build-samples.ts` 用 zlib 压缩后再入库。
- **导出 .fabricmesh**：便于在版本库中 diff 的文本网格。
- **重新载入导出文件**：会重算诊断并与导出记录比对；几何、拼缝、诊断任一不一致都会在「导出」面板里列出。

## 概念约定

- **布面空间**：世界单位，Y 轴向下，和画面像素一致。
- **纹理坐标**：标准化 UV，V 向下；超出 [0,1] 视为重复取样。
- **顶点按位置焊接**：两个顶点只要布面坐标相同（6 位小数）就视为同一点。这是断开拼缝的实现方式——拼缝两侧各有一份顶点、UV 不同，但位置相同，因此布面依然严丝合缝。
- **拼缝声明**：只表达意图，不虚构邻接关系。
  - `continuous`：两侧应使用同一纹理坐标线；实际不一致会报「意外断开」。
  - `split`：两侧有意取不同纹理坐标；实际相同会报「断开但两侧相同」。
  - 未声明的共享边也会自动按连续检查。
- **诊断**：
  - 每个三角形的雅可比 `J = d(布面)/d(UV)`；`det < 0` 为翻面；最小奇异值低于阈值视为塌陷。
  - 「明显拉伸」用**相对**指标：相对网格自身中位密度 `stretchRatio`、以及各向异性 `anisotropy`，避免作者尺寸影响结论。
  - 全程重复偏移会单独标为「整重复位错开」（视觉连续但并非同一条 UV 线）。
- **坏片处理约定**：`retain` 时翻面/塌陷三角形用洋红绘制并保留在原位，但不再参与「明显拉伸」的正常着色；`disable` 时只移除其填充，轮廓仍绘制，便于找回并修回有效几何。两种模式都不修改文档，也不影响导出，除非你在导出预览时选择停用。

## 验证

```sh
npm test             # 类型检查 + 84 项 Node 测试
npm run test:browser # 28 项真实 WebGL 浏览器冒烟测试（需要本机 Chrome/Chromium）
```

- `npm test` 覆盖：诊断与拼缝几何、雅可比/奇异值、焊接拓扑、命令与撤销/重做、导出→重载指纹一致性、编辑顺序无关性、PNG 编解码确定性、CPU 光栅器在两色纹理下的拼缝连续/断开像素表现、拾取与视图变换、面板 HTML。
- `npm run test:browser` 用无头 Chromium 打开真实页面，驱动真实 WebGL：确认两个画布栏都有内容、断开拼缝叠加层可见、翻面三角以洋红显示、拖动后修复、撤销/重做恢复同一诊断指纹、坏片停用确实减少填充、导出 JSON 重载无偏差。截图写入 `artifacts/`（已加入 `.gitignore`）。

浏览器测试会依次查找：环境变量 `CHROME_BIN`、Playwright 的 Chromium 缓存、系统 Chrome。找不到会明确报错。

## 目录

```
src/core/     纯函数数据层：类型、几何、诊断、焊接拓扑、历史、编辑命令、
              导入导出、PNG 编解码、CPU 参考光栅器、拾取
src/webgl/    WebGL2 上下文、shader、双栏视图（布面 + 纹理坐标）
src/app/      应用控制器（无 DOM，可被 Node 测试直接驱动）、交互、面板 HTML
src/main.ts   DOM 绑定；仅负责把输入接到控制器
samples/      三个自带样例（网格 + 纹理 + 参考预览/报告）
tools/        样例生成器、Node 端 PNG 解码器
tests/        Node 单元测试 + 浏览器冒烟测试
```

## 与仓库中原有 renderer 的关系

本工具是独立目录，不改动也不依赖 `renderer/` 的 Canvas 2D 场景示例。两者目标不同：`renderer/` 画的是 2D 场景树，本工具做的是网格贴图诊断。

## 来源说明

本工具为本次任务新写的原创代码，未从任何上游渲染器或游戏引擎复制。样例纹理（格纹）与网格均由 `tools/build-samples.ts` 程序化生成。
