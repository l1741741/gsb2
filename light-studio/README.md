# Light Studio — 二维灯光离线预演工具

面向舞台灯位预演的纯前端 2D 工具：在浏览器里拖动灯具，即可实时观察墙、
柱子、带门缝隔断之后的阴影与照度变化。全部数据为本地 JSON，不依赖任何
第三方包或远程资源，与仓库内既有的 `renderer/` 示例相互独立。

## 适用场景与边界

- 用于**平面（2D）离线预演**：回答“这盏灯能不能照到那个位置、由哪几盏灯照亮、
  门限以下的暗区在哪”。
- 不是光学仿真：照度是相对值（二次衰减模型），不计算反射、散射、色温与体积光。
- 所有几何与照度计算都在**世界坐标**中完成，画布缩放/平移只改变绘制矩阵，
  不改变任何可照亮范围与照度读数。

## 运行

需要 Node.js 20+（仅用于测试与复核脚本）和一个现代浏览器。

```sh
cd light-studio
npm test          # 32 个单元/管线测试
npm run demo      # http://localhost:4174/demo/
```

浏览器打开后左上角面板可切换三个内置样例：走廊与门缝、并排墙角（共享顶点）、
相交光束与圆柱。

## 操作

| 操作 | 效果 |
| --- | --- |
| 拖动灯体 | 移动灯具（静止灯不重算、不闪动） |
| 按住 Alt/Option 拖动灯 | 修改灯具朝向 |
| 空白处拖动 | 平移视图 |
| 滚轮 | 以指针为锚点缩放 |
| 探针模式 + 点击 | 读取该点总照度与逐灯贡献 |
| 灯具列表“禁用/启用” | 逐盏开关，禁用灯不产生任何贡献 |
| 灯具参数编辑器 | 精确设置位置、朝向、半锥角、射程、功率、颜色 |
| 照度门限 / 网格单元 | 设置暗区分界并叠加显示低于门限的区域 |
| 导出方案 JSON / 预览 PNG | 保存方案（含复核快照）与当前画面 |
| 导入方案 JSON | 以相同参数恢复方案并可立即复核 |

命令行复核（不开浏览器，与浏览器探针同一套计算代码）：

```sh
node scripts/verify-plan.mjs 方案.json
```

## 场景数据格式

```jsonc
{
  "schemaVersion": 1,
  "name": "方案名称",
  "bounds": { "width": 1000, "height": 420 },
  "settings": { "threshold": 0.15, "cellSize": 14, "falloff": "quadratic" },
  "walls": [
    { "id": "wall-1", "from": { "x": 40, "y": 60 }, "to": { "x": 960, "y": 60 } }
  ],
  "partitions": [
    {
      "id": "partition-1",
      "from": { "x": 500, "y": 60 },
      "to": { "x": 500, "y": 360 },
      "openings": [ { "start": 190, "end": 250 } ]
    }
  ],
  "columns": [
    { "id": "column-1", "center": { "x": 500, "y": 350 }, "radius": 45 }
  ],
  "lights": [
    {
      "id": "L1", "name": "走廊左灯",
      "x": 250, "y": 180,
      "aim": 0,                 // 弧度，0 指向 +x；全向灯忽略
      "fov": 1.0,               // 半锥角（弧度），>= PI 为全向
      "range": 340,             // 最大照明距离，世界单位
      "power": 1,               // 满功率相对照度
      "color": "#ffd9a0",
      "enabled": true
    }
  ],
  "checkpoints": [
    { "id": "cp-1", "x": 900, "y": 320, "expect": "dark",
      "lights": null, "note": "应全暗/部分相交 partial/直接可见 visible" }
  ]
}
```

- 墙与隔断均为轴对齐线段；隔断的 `openings` 用沿线段方向的世界坐标区间表示门缝，
  展开后只是“跳过门缝的若干遮挡线段”，门缝处不存在任何遮挡体。
- 柱子用 32 边多边形近似圆参与遮挡计算。
- 导出的 JSON 额外带 `review` 复核快照（门限、逐检查点总照度、贡献灯），
  重新导入后可一键复核，保证同参数同结果。

## 关键算法

### 可见多边形（`src/visibility.js`）

从灯心对每个遮挡线段端点的真实角度以及 `±1e-5` 弧度各投一条射线，再按固定
角度步长补投扫描射线（保证射程圆弧边界平滑），取每条射线的最近交点，按角度
排序形成可见多边形。

- 误差只存在于端点周围 1e-5 弧度的楔形内，**短边与共享顶点（T 形接头、墙角）
  附近不会出现成片漏光或黑边**；
- 遮挡判定使用严格跨立（`properCrossing`），视线恰好擦过门缝边缘或共享顶点时
  允许通过，不会把门缝光误杀；
- 聚光灯只在 `[aim-fov, aim+fov]` 角度域生成射线，域外不可见。

### 照度与叠加（`src/lighting.js`）

单灯照度 `power / (1 + (d / (range/2))^2)`，超出射程或落在可见多边形外为 0。
多灯按灯具数组的固定顺序逐盏累加，结果只取决于数据而与绘制顺序无关。

应用层为每盏灯单独缓存可见多边形：拖动一盏灯时只有该灯重算，静止灯的缓存
原样复用，因此静止照明不会随绘制闪动。

### 暗区门限（`buildDimGrid`）

在世界坐标中按 `cellSize` 网格采样总照度，低于 `threshold` 的单元用半透明
紫色叠加。网格与相机无关，缩放和平移不改变判定。

## 目录结构

```
light-studio/
├── demo/                # 浏览器应用（index.html / app.js / styles.css）
├── src/                 # 纯计算与绘制模块，无 DOM 依赖的部分可在 Node 直接测试
│   ├── geometry.js      # 射线/线段相交、角度工具、点在多边形内
│   ├── scene.js         # 数据模型、校验、隔断开口展开、序列化
│   ├── visibility.js    # 可见多边形
│   ├── lighting.js      # 照度模型、多灯叠加、探针、暗区网格、缓存签名
│   ├── camera.js        # 世界/屏幕坐标互转
│   ├── render.js        # Canvas 2D 分层绘制（加法混合叠加灯光）
│   └── samples.js       # 三个内置样例与检查点
├── scripts/verify-plan.mjs
└── tests/               # node --test 测试（几何、可见性、照度、场景、样例、渲染管线）
```

## 验证与局限说明

- `npm test` 覆盖：严格跨立遮挡、门缝透光、T 形共享顶点、锥角域、照度衰减、
  禁用/启用、暗区网格、序列化往返、相机不变性、三个样例的全部检查点、渲染分层。
- 渲染管线测试使用录制式 Canvas 2D 上下文验证绘制契约，**不能替代浏览器中的
  真实像素确认**；像素效果请用 `npm run demo` 打开样例人工检查。
- 柱子为 32 边近似圆，遮挡误差随半径增大而减小；灯心落入遮挡体内部等退化情形
  兜底为零照明区域，不抛出异常。
