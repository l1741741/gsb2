# Grid Calibrator / 网格畸变校正工具

一个零依赖、完全本地运行的 JavaScript + Canvas 工具，用于处理同一台俯拍相机产生的网格弯曲、四角变形和批量扫描图校正。

它不会上传图片。推荐通过静态服务器打开，避免浏览器对 ES Module 的 `file://` 限制。

## 启动

```sh
cd grid-calibrator
npm run demo
```

然后打开 <http://127.0.0.1:4174/>。

也可以在该目录运行：

```sh
python3 -m http.server 4174 --bind 127.0.0.1
```

需要 Node.js 20+ 来运行测试；浏览器建议使用当前版本的 Chrome / Edge / Firefox / Safari。

## 验证

```sh
cd grid-calibrator
npm test
```

测试覆盖：

- 数字弯曲网格的中心、边缘和四角位移量；
- 三次/二次多项式拟合与保留检查点残差；
- 点太少、集中在一角时拒绝新拟合并保留上一次可用模型；
- 拖动交点的合并历史、撤销和重做；
- 缩放/平移后的屏幕坐标到原图像素换算；
- 校正逆映射越界、透明像素和最大有效矩形；
- 配置保存/恢复后的模型、裁切和校正像素一致性；
- 图片尺寸不一致时的明确拦截。

## 使用流程

1. 在“标定图”中加载自己的扫描/标定照片，或点击 **生成弯曲标定网格**。
2. 设置网格列数、行数，点击 **铺设初始点阵**。
3. 使用 **选择/拖动** 把点拖到真实交点。滚轮以光标为中心缩放，拖动空白处平移；在原图、校正图和对齐网格视图中也可以缩放和平移。缩放和 DPR 转换不会改变像素坐标。
4. 选中点后可以修改对应的零基内部行列（界面显示为 `R1/C1` 这样的一基编号），也可以把点切换为：
   - **拟合点**：参与多项式拟合；
   - **检查点**：不参与拟合，只显示真实残差。
5. 至少保留几个检查点。右侧面板显示检查点 RMS、最大值、中心残差、边缘残差和逐点残差条。
6. 如果当前点少于 8 个、行列跨度不足或空间分布集中，界面会提示补点；已有可用模型会继续保留，不会被坏拟合替换。
7. 加载待校正图片。只有宽高与标定图完全一致时才允许校正/导出；尺寸不同会显示红色提示并阻止静默套用。
8. 在 **原图 / 校正图 / 对齐网格** 三个视图间检查效果。对齐网格使用同一组理想行列坐标叠加到校正结果。
9. 导出 PNG：
   - **保留透明边界**：按当前裁切范围输出，逆映射到源图之外的像素为透明；
   - **仅输出最大有效矩形**：用直方图最大矩形算法裁掉越界/透明边界。
10. 点击 **保存标定配置** 可保存 JSON，包含图片 Data URL、点位、角色、行列、模型系数、输出间距和裁切范围。恢复配置后使用的是同一份模型与裁切，因此导出结果一致。

## 自带示例

点击：

- **生成弯曲标定网格**：生成 960×720、11×8 交点的数字弯曲网格。红点是预留检查点，不参与拟合。
- **生成弯曲检查图**：生成同尺寸、同一弯曲函数的棋盘/检查图，并自动进入校正预览。

示例弯曲包含径向畸变、轻微透视和边角卷曲。面板会给出已知的弯曲位移：

- 中心点位移；
- 边缘中点平均/最大位移；
- 四角平均/最大位移。

自带示例默认使用比最外层交点再向外 1.5 个网格单位的裁切，因此会立即出现少量越界透明像素，面板会显示越界比例和最大有效矩形尺寸。把裁切扩大到 `-2.5 / 12.5` 和 `-2.5 / 9.5` 可以看到更明显的透明边界；点击“重置为网格外半格”则回到无越界的紧贴网格范围。

如果已经载入或标记了自己的标定图，再点击 **生成弯曲检查图**，工具会先请求确认是否替换当前标定；取消后只生成检查图并继续尝试当前标定，不会静默清空标记或撤销历史。

## 校正模型

工具拟合从理想网格坐标到标定图像素的映射：

```text
sourceX = Px(col, row)
sourceY = Py(col, row)
```

- 8–11 个合格拟合点：二次多项式（6 项/轴）；
- 12 个以上合格拟合点：三次全多项式（10 项/轴）；
- 行列坐标先做中心化和统一缩放，降低正规方程的数值病态；
- 使用带部分选主元的高斯消元和很小的相对岭项。

导出时遍历输出像素，将输出像素中心转换为理想行列，再用模型逆映射到源图并做双线性采样。这个方向天然支持透明越界区域，不需要反解多项式。

## 目录

```text
grid-calibrator/
├── index.html              # 单页工具界面
├── styles.css
├── package.json
├── README.md
├── src/
│   ├── app.js              # DOM/事件/导出/文件流程
│   ├── calibration.js       # 拟合编排与保留旧模型
│   ├── config.js            # JSON 配置序列化/校验
│   ├── distortion.js        # 数字弯曲函数与测量
│   ├── math.js              # 最小二乘、求解、残差、点位评估
│   ├── state.js             # 不可变文档操作、撤销栈、尺寸检查
│   ├── synthetic.js         # Canvas 生成网格和检查图
│   ├── view-renderer.js     # Canvas 视图绘制
│   ├── viewport.js          # 缩放/平移/命中坐标
│   └── warp.js              # 像素校正、越界、有效矩形
└── tests/                   # Node 内置测试运行器测试
```

已有 `renderer/` 示例保持不变。
