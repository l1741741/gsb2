# Source origin

The paper-fold preview was written for this GSB2 task set in 2026-11. It is original
code in this repository, not copied or forked from an upstream CAD, origami-simulation,
or physics engine project. It reuses only the repository's own dependency-free
conventions (plain ES modules + Canvas 2D, Node's built-in test runner). The bundled
sample models are synthetic geometric fixtures, not real product designs.
