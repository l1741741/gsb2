# Source origin

The `wavrepair` tool in this directory was written for this GSB2 task set on
2026-11-28. It is original starter code in this repository and was not copied
or forked from an upstream project. It uses only the Python standard library
(`wave`-compatible RIFF parsing is implemented directly in `wavio.py`, since
`audioop` was removed in Python 3.13). The demo takes are synthetic signals
generated by `wavrepair/demo.py`; they do not represent a real recording,
person, or organization.
