# poster_diff — 离线 PNG 海报差异对比器

面向印前检查的本地图片对比工具：输入两张 PNG，生成一个**完全离线、可平移缩放**的
HTML 差异报告。纯 Python 标准库实现（自带 PNG 编解码，不依赖 Pillow / numpy，
前端不依赖任何 CDN 或网络资源），与仓库内 `renderer/` 示例相互独立。

## 适用场景

- 整张预览看不出的边缘误修，需要放大定位；
- 透明边 / 透明孔的隐藏 RGB 不应被算作外观改动；
- 两版导出存在整数像素错位，需要先对齐再比较，并单独标出只有一张图覆盖的区域；
- 大图（数千万像素）需要分区处理，且跨分区的同一处改动只能统计一次；
- 报告要能直接发给同事双击打开，不能要求联网或起服务。

## 快速开始

```sh
# 1. 生成一对演示海报（可选）
python3 demo/make_sample.py

# 2. 生成差异报告（在 poster_diff/ 目录下执行）
PYTHONPATH=. python3 -m poster_diff \
  -r demo/sample/poster_a.png \
  -c demo/sample/poster_b.png \
  -o demo/sample/report \
  --offset-x 6 --offset-y 4

# 3. 直接用浏览器打开
open demo/sample/report/index.html   # 沙箱环境外执行；file:// 即可，无需服务器
```

`PYTHONPATH=.` 仅在未安装包时需要；执行 `pip install .` 后可直接用
`poster-diff` 命令或 `python3 -m poster_diff`。

## 命令行参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `-r, --reference` | 必填 | 参考图 A（坐标原点） |
| `-c, --candidate` | 必填 | 候选图 B |
| `-o, --output` | 必填 | 报告输出目录 |
| `--offset-x / --offset-y` | 0 / 0 | B 相对 A 的整数像素偏移，支持负值 |
| `--appearance-threshold` | 16 | 合成后颜色差超该值（0–255）才算外观改动 |
| `--alpha-threshold` | 16 | alpha 差超该值才算透明度改动 |
| `--merge-gap` | 2 | 外接框间距 ≤ 该值的相邻改动归并为一块（像素） |
| `--connectivity` | 8 | 连通域标注用 4 或 8 连通 |
| `--min-block-area` | 1 | 小于该面积的改动块直接丢弃 |
| `--background` | `#ffffff` | 半透明像素合成底色，支持 `#rrggbb` 或 `r,g,b` |
| `--tile-size` | 512 | 处理分区边长；报告展示瓦片固定 256px |
| `--title` | 输出目录名 | 报告标题 |

## 报告内容

打开 `index.html` 后左侧为面板，右侧为可拖拽平移、滚轮缩放的画布：

- **图层切换**：外观差异热力图 / 透明度差异热力图 / 覆盖区域 / 参考图 A / 候选图 B；
- **块列表**：每个改动块列出矩形范围（参考图坐标）、改动像素面积、外观与 alpha
  峰值差异，点击任意一块即平移缩放到原图对应位置；画布上点选也会反向选中列表项；
- **单边覆盖区**：参考图独有（绿）与候选图独有（红）的连通区域单独成块列出，
  错位产生的条带会直观显示；
- **总览**：共有/单边像素数、超阈值像素数、平均差异、实际使用的全部参数；
- 高层预览只加载低分辨率瓦片，原始分辨率的两张图**不会**整体放进页面；
  瓦片以 base64 形式存放在本地 JS shard 中，按可见区域按需注入 `<script>`，
  因此 `file://` 下不需要 `fetch()` 也不会有 CORS 问题。

输出目录结构：

```
report/
├── index.html            # 报告入口，双击离线打开
├── report_data.js        # 全部统计数据（file:// 友好的 JS 赋值）
├── stats.json            # 同一份数据的 JSON，供脚本复算
├── diff_blocks.csv       # 改动块 + 覆盖块表格
├── reproduce 命令        # 记录在 stats.json 的 reproduce 字段，参数齐全可直接重跑
├── assets/               # 两张 ≤512px 的合成缩略图（非原始分辨率）
├── viewer/               # 查看器 app.js / styles.css
└── tiles/                # 各图层、各金字塔层级的 256px 瓦片 shard
```

## 关键语义

### 1. 对齐与覆盖区域

B 按 `(offset_x, offset_y)` 放置到以 A 为原点的共享画布上，所有报告坐标都是
**参考图坐标**。两图交集为共有区域，只在一张图内的像素按 4/8 连通标注为
`reference_only` / `candidate_only`，两类区域即使对角相接也不会合并。

### 2. 外观差异 vs 透明度差异

- alpha 差值是独立指标，单独成图、单独超阈值统计；
- 外观差异先把每个像素按 `--background` 合成到不透明底色上，再比较 RGB 最大通道差，
  因此半透明颜色的比较结果随所选底色变化且可复现；
- 两图 alpha 都为 0 的像素，其存储的 RGB（"隐藏颜色"）一律不计入外观差异；
- 一个块同时含外观超阈值像素和 alpha 超阈值像素时标记为 `both`。

### 3. 阈值归并与跨分区去重

标注在整张画布的逐行扫描上进行（只保留上一行标签，内存与行数无关），
并查集实时合并标签——即使改动横跨多个处理分区，它仍然是**一个**连通域、
统计一次。之后再按 `merge_gap` 对相邻连通域的膨胀外接框做二次归并，
最后输出每块的外接矩形、面积和两个指标的峰值。

### 4. 大图处理与瓦片金字塔

比较按 `--tile-size` 分区流式进行，单分区结果立即写入瓦片缓冲；
展示层为每个图层构建 2× 盒式降采样金字塔（256px 瓦片），
适合窗口的缩放级别只加载对应层级的 shard。

## 设计约束

- 零第三方依赖：沙箱/离线环境无法安装 Pillow 时仍可运行；PNG 解码支持
  灰度（含 1/2/4 位）、RGB、调色板（含 tRNS）、GA、RGBA 与 16 位降采样，
  不支持 Adam7 隔行 PNG（会明确报错，需先在导出工具里展平）。
- 性能参考（Apple Silicon，纯 CPython 3.14）：2400×3200 两图比较约 3 秒，
  完整报告约 13 秒，峰值内存约 220 MB。
- 所有参数、输入文件 SHA-256、几何信息都写入 `stats.json`，配合 `reproduce`
  字段可在任意机器上原样复算。
