# Source origin

This waterway drill was written for this GSB2 task on 2026-11-28. It is original
starter code in this repository, built from scratch. It is not copied or forked
from an upstream game, engine, or physics simulator. The sample levels and their
pool/gate layouts are invented for this drill and do not represent any real
utility, plant, or location.

The tool lives in its own directory (`waterway-drill/`). The pre-existing
`renderer/` sample is untouched and remains available on its own.
