# 疏散路线矢量排版工具（evac）

本地矢量路线排版工具：读取已审核的疏散路线 JSON，按楼层输出矢量示意图。
只做**排版与绘图**，不做路线规划——路线、楼层、门点全部来自输入数据。

## 运行

```sh
npm test        # Node.js 20+，无第三方依赖
npm run demo    # 然后打开 http://localhost:4174/demo/
```

演示页支持：楼层切换、滚轮缩放（光标为中心）、拖拽平移、打开本地 JSON、
导出当前层 SVG。示范数据为两层楼，覆盖共用分支、反向共边和断开线路三种情况。

## 数据格式（`demo/data/demo.json`）

```jsonc
{
  "schema": "evac-plan/1",
  "floors": [{ "id": "F1", "name": "一层", "level": 1 }],
  "nodes":  [{ "id": "D-N1", "floor": "F1", "kind": "exit", "x": 330, "y": 60, "label": "北门" }],
  "stairs": [{ "id": "ST1", "flight": "1#", "landings": [
    { "floor": "F1", "node": "S1-F1" }, { "floor": "F2", "node": "S1-F2" }] }],
  "routes": [{ "id": "R1", "label": "展厅疏散", "color": "#d62728", "legs": [
    { "floor": "F1", "path": ["R-101", "A1", "S1-F1"] },
    { "floor": "F2", "path": ["S1-F2", "C2", "D-E2"] }] }]
}
```

- 节点 `kind`：`exit`（安全出口）、`room`（起点房间）、`waypoint`（途经点）、`stair`（楼梯口）。
- 一条路线由若干 `legs` 组成，每段属于一个楼层；相邻两段必须经同一部楼梯
  （`stairs[].landings`）换层，否则视为断开的链路。
- 坐标为世界单位（如图纸毫米），缩放只改变视图，不改变数据。

## 排版规则

1. **楼层与延续关系**：每层一张图。路线换层处在楼梯口标注
   `续 → 二层` / `← 接 一层`，延续关系双向可查。
2. **共用段**：同一条无向走廊边被多条路线使用时，按 `(路线id, 方向)` 排序
   分配侧向车道（顺序可复现，与 JSON 中路线先后无关）；反向通行各占一条车道，
   各自带方向箭头；汇入/分开处在节点前修剪并以二次贝塞尔过渡，互不压盖。
3. **楼梯**：换层不画平面连线，画楼梯符号；符号上的编号（`flight`）和
   上/下方向（由各楼层 `level` 推出）都对应回原数据。
4. **缩放与导出**：路线描边使用 `vector-effect="non-scaling-stroke"`，
   箭头、文字、车道间距按 `1/scale` 换算，缩放时屏幕上的线宽与箭头恒定。
   屏幕显示与导出文件由同一个生成器（`src/svg.js` 的 `renderFloorSvg`）产出，
   几何必然一致。
5. **校验**：载入时校验楼层/节点/楼梯/路线引用，错误指明路线、楼层与节点
   （如 `路线 R4 第 2 段：楼层 F2 上不存在节点 "N-404"`）；含缺失节点的段不绘制，
   其余段照常绘制。

## 结构

- `src/model.js` — JSON 载入与校验，产出内部模型 + 错误列表。
- `src/layout.js` — 单层排版：车道分配、路径几何、箭头、楼梯与延续标记。
- `src/svg.js` — SVG 生成（屏幕与导出共用）。
- `demo/` — 演示页与两层示范数据。
- `tests/` — 18 个用例：车道顺序可复现、反向共边、断开链路报错定位、
  缩放时线宽/箭头恒定、导出确定性、楼梯编号方向对应原数据。
