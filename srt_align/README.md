# srt_align — 离线 SRT 时间轴对齐工具

同一集短片有两套字幕时，把**译文**字幕的文字（含字幕员手工换行）原样保留，
只把它的断句时间对齐到**原版**字幕的时间轴。支持少量拆句（一对多）、
合句（多对一）、缺行、孤立行和人工锚点，**不做任何翻译**，全程离线、
仅使用 Python 标准库。

## 解决什么问题

- 两份 SRT 各自带独立序号，且存在少量时间偏差；
- 译文把一句拆成多条、或把多条合成一条；
- 译文漏译（原版有、译文缺）或多出孤立行（如字幕组署名）；
- 个别条目输入顺序错乱；
- 需要人工钉死少量已确认的对应关系。

## 用法

```bash
# 隔离模式运行，输出对齐后的 SRT 与两份报告
python3 -I align_srt.py 原版.srt 译文.srt \
    --anchors anchors.txt \
    --output aligned.srt \
    --report report.json \
    --text-report report.txt
```

不带 `--output` 时 SRT 写到标准输出，文本报告始终写到标准错误，
因此 `python3 -I align_srt.py a.srt b.srt > out.srt` 可以直接用。
`--strict` 下出现挤不下、未匹配或坏块时退出码为 1，便于接入流水线。

### 锚点文件

每行一个已确认对应，等号两侧是字幕块在**各自文件中的物理位置**
（从上到下 1 基计数，与文件里写的序号无关），多位置用 `+` 连接：

```text
3 = 2          # 原版第 3 条 对应 译文第 2 条
2 = 3+4        # 原版一条 对应 译文两条（拆句）
6+7 = 5        # 原版两条 对应 译文一条（合句）
```

规则：

- 锚点在两侧都必须严格递增、不得重复引用或交叉，冲突时**整份锚点被拒绝**
  并给出原因，程序终止（退出码 2），不会静默忽略；
- 若输入 SRT 本身错序，锚点按**重排后的时间顺序**校验，时间交叉同样拒绝；
- 自动匹配只能在相邻锚点切出的区间内进行，**不可能跨过锚点**。

## 工作原理

1. `srtio.py`：容错解析（BOM、CRLF、点号毫秒、缺序号、坏块），
   错序输入按开始时间稳定重排并产生 `order_fixed` 警告；写出时重新连续编号，
   保证是合法 SRT。
2. `anchors.py`：锚点语法、范围、越界、物理顺序与时间顺序的全部冲突校验。
3. `engine.py`：锚点把两条序列切段，段内做**分段半马尔可夫 DP**——
   每个组可在两侧各消费 1–3 条（`--max-run` 可调），下标只增不减，
   因此顺序天然不会被打乱。组成本只看时间窗（重合度、中心点、窗长、
   内部空洞），不依赖语言文字。跳过条目是与组匹配并列的显式动作，
   孤立行不会被硬塞进相邻组；带内部时间空洞的合并罚分高于显式跳过，
   避免把缺行吞进大组。
4. 时间约束：每组译文被整体约束在原版组的 `[最早开始, 最晚结束]` 窗内，
   按各条原时长比例分配、顺序铺排、互不重叠；译文文字和手工换行原样保留。
   当某条按字符数估算的最短时长超过可分配时长时，输出 `tight_span`
   明确警告，提示人工介入。
5. `report.py`：导出每组两侧来源条目（物理位置、原序号、原时间、文字、
   换行数、对齐后时间）、两侧未匹配项和全部诊断。

## 诊断码

| 代码 | 含义 |
| --- | --- |
| `order_fixed` | 输入错序，已按开始时间重排 |
| `invalid_block` | 坏块（缺时间轴/时间非法/序号异常），已跳过或回退 |
| `empty_text` | 字幕正文为空 |
| `unmatched_original` | 原版有条目、译文缺行，未并入任何组 |
| `unmatched_translation` | 译文孤立行，原版无对应，未硬塞进相邻组 |
| `tight_span` | 译文在原版窗内确实挤不下，需人工处理 |
| `cps_high` | 字符速率偏高的可读性提示 |
| `anchor_forced` | 该组由人工锚点强制对应 |

## 样例与测试

```bash
bash examples/run_demo.sh           # 端到端演示（分合句/错序/缺行/孤立行/锚点冲突/挤不下）
python3 -I -m unittest discover -s tests -v
```

`examples/` 下的两份 SRT 与 `anchors.txt` 是一套可复查的最小数据集：
译文序号故意从 10 开始且文件内错序，包含 1→2 拆句、2→1 合句、一条缺行、
一条 90 秒处的孤立署名行。演示产物写到 `$TMPDIR/srt_align_demo/`。

## 边界与取舍

- 工具不翻译、不改写译文文字，只动时间轴；输出中译文孤立行默认保留并
  沿用其原时间（避免丢内容），`--drop-orphans` 可剔除。
- DP 复杂度约为 O(n·m·max_run²)，面向「少量拆合句」的字幕规模；
  超长文件可按锚点分段后逐段运行。
- 时间约束是确定性的比例分配；`tight_span` / `cps_high` 只警告不改字，
  最终取舍留给人工。
